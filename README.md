##  Descripción

**Mi Biblioteca Virtual** es una aplicación pensada para quienes aman leer y quieren mantener todo ordenado. Puedes registrar los libros que tienes, marcar cuáles ya terminaste, ponerles una calificación de 1 a 5 estrellas y buscar por título, autor o género. Todo se guarda en una lista clara que puedes consultar desde cualquier dispositivo.
